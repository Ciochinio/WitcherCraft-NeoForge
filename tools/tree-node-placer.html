Tree Node Placer

Drag nodes to lay out each branch. Turn on Link mode to draw prerequisites (click a parent, then a child). The purple T1-T5 boxes are the sub-tab row (drag any one: x is per tab, the row height is shared) and the Mutagens tab shows the inventory block (drag it). Output regenerates PerkTree.java → copy → paste over the file.
Editing
In link mode, click a node then another to add a prerequisite; click the small × on a link to remove it. Cycles and duplicates are rejected. Move mode: drag to reposition, arrow keys nudge.
Canvas
Nodes are fixed vanilla slots: an 18x18 frame with a 16x16 icon (the Skills panel is drawn 1:1 at normal GUI scale). Keep nodes clear of the sub-tab row (T1-T5) at the top.
Background
Guide only - never exported. The full frame is shown; faint dashed boxes are the sub-tab row and the equip grid (read-only reference, from PerkEquipLayout) so you can align both sides.
Import from Java
Paste the current PerkTree.java to load its node positions + prerequisites into the editor. Unknown perk ids are ignored; any perk missing from the paste keeps its default-grid position. An older file with bigger nodes (NODE_SIZE above 18) is converted by shrinking each node around its centre.
