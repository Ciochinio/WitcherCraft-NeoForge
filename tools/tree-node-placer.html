Tree Node Placer

Drag nodes to lay out each branch. Turn on Link mode to draw prerequisites (click a parent, then a child). Output regenerates PerkTree.java → copy → paste over the file.
Editing
In link mode, click a node then another to add a prerequisite; click the small × on a link to remove it. Cycles and duplicates are rejected. Move mode: drag to reposition, arrow keys nudge.
Canvas
Background
Guide only - never exported. The full frame is shown; faint dashed boxes on the right are the equip grid (read-only reference) so you can align both sides.
