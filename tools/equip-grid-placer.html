Equip Grid Placer

Drag boxes (resize the medallion by its corner handle). Output regenerates PerkEquipLayout.java live → copy → paste over the file. Coordinates are panel-local Minecraft GUI pixels: the Skills panel is drawn 1:1 at normal GUI scale. This tool owns the right side (equip grid, sockets, bonus labels, medallion) and every colour; the sub-tabs, tree nodes and Mutagens inventory are in tree-node-placer.html.
Nothing selected. Click a box to select; drag to move. Arrow keys nudge (Shift = x5).
Panel
Every cell (tab, perk slot, mutagen socket, tree node) is a vanilla slot: an 18x18 frame with a 16x16 icon (dashed inner square). The size is fixed, not exported as a setting. The panel must fit the screen at the player's GUI scale, or it is outlined red in game.
Medallion
The medallion is just the decorative centre piece today - it does nothing. Turn it off to hide it. Drag its corner handle to resize.
Bonus labels
Select a B1-B4 box (the bonus text for socket M1-M4, e.g. "+15 Increased Damage", one line per bonus, 10px apart). Text is aligned inside the box and is not clipped, so leave room for longer lines. Each label gets a background behind its text (colour below). A scale below 1 shrinks the text; values other than 0.5 / 1 can look slightly uneven with Minecraft's pixel font. Right-aligned text grows leftwards from the box's right edge.
Colours (ARGB)
Every colour the Skills page draws. Type #AARRGGBB (AA = opacity, FF = solid) or pick an RGB colour (keeps the alpha). Exported into PerkEquipLayout.java.
Connectors & display
Editor guide only - links each mutagen socket to its 3 slots. Not exported.
Snapping & background
Load your eventual panel art to place boxes against it. The image is only a visual guide - it is never exported.

Slot index fixes its mutagen group (1-3→g1, 4-6→g2, 7-9→g3, 10-12→g4). Socket Mn belongs to group n and buffs from the perks in its group. The tree nodes are placed with tree-node-placer.html; keep them clear of the tab row.
Import from Java
Paste the current PerkEquipLayout.java to load its values into the editor. An older file with bigger cells (SLOT_SIZE / SOCKET_SIZE above 18) is converted by shrinking each cell around its centre; a file without a tab row or inventory block keeps the seeded ones.
