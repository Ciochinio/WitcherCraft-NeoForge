Alchemy Layout Placer

Drag any slot, the Brew button, the book button, the message, the optional frame image, or the inventory (the hotbar drags on its own). Rings, the pentagon frame and the spokes follow their slots. Ring sizes snap to even numbers so rings stay centred on the 18px slots. Yellow corner handles resize the block, book panel, frame image, Brew button, book button and message width. Coordinates are normal GUI pixels inside the slot block (slot x/y = the 16x16 item position, like vanilla), not the 640x360 shell canvas. Output regenerates src/main/java/net/redboltmedia/witchercraft/AlchemyLayout.java → Copy → paste over the file. Art previews load from ../src/main/resources.
